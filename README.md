# Mini Quora (Full Stack)

## Features
- User can create, edit, delete posts
- AI generates post content
- AI improves writing
- Authorization (only owner can edit/delete)

## Tech Stack
Frontend:
- React.js

Backend:
- Node.js
- Express.js

Database:
- MySQL

AI:
- Groq API

## How to Run

### Backend
cd backend
npm install
npm start

### Frontend
cd frontend
npm install
npm start
